* 统计给定时间到现在所有人提交次数
git log --since="2024-04-15" --until="now" --pretty=format:'%aN' | sort | uniq -c | sort -k1 -n -r

--since="2024-04-15"：指定开始日期为 2024 年 4 月 15 日。
--until="now"：指定结束日期为当前时间。
--pretty=format:'%aN'：只输出提交作者的名字。
sort：对输出进行排序。
uniq -c：统计每个作者的提交次数。
sort -k1 -n -r：按提交次数降序排序。

* 统计每个开发者在指定时间段内的代码修改行数，并包括增加的行数、删除的行数和总行数的完整命令：

git log --since="2024-04-15" --until="now" --format='%aN' | sort -u | while read name; do
echo -en "$name\t"
git log --since="2024-04-15" --until="now" --author="$name" --pretty=tformat: --numstat | \
awk '{
    if ($1 ~ /^[0-9]+$/) {
        add += $1
        subs += $2
        loc += $1 - $2
    }
} END {
    printf "added lines: %s, removed lines: %s, total lines: %s\n", add, subs, loc
}' -
done
